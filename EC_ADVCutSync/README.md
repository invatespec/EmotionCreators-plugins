# EC_ADVCutSync

HEdit 的 ADV Part 编辑器插件：对当前打开的 Part 做一次性的 cut 状态数据整理，消除切 cut 时的卡顿与 BGM 重播。

## 背景

EC 里如果各 cut 把角色相关状态全部设为显式值，切 cut / 试玩推进时每进一个 cut 都会重刷状态：
服装切换（`CoordinateInfo.Adapt` type 1/2）触发整套 `ChaControl.Reload`，穿脱/饰品/汁液逐项重算，
BGM 同曲也重启（`isAssetEqualPlay = true`）。把冗余的显式值转成游戏原生的"维持"表示即可避免。

## 功能

- **中间 cut 维持化**：逐角色（各自独立生效链）沿 cut 序列追踪生效状态，仅当某 cut 的值与进入前的生效状态相同时才转维持
  （服装 type `-`、穿脱/饰品/汁液 `-1`、音声 type 0、BGM `引き継ぐ`）；引入新状态的 cut 保留显式，播放效果与原数据等价。
  生效链只推进**可见 cut** 的显式值——隐藏角色整段跳过状态应用，其显式值从未生效，不参与判定。
- **尾 cut 状态型快照**：对尾 cut 中显示的角色，把维持项显式写入"可见生效链（含尾 cut 自身显式值）的最晚显式值"——
  即剧情终态。例：首cut全穿→脱上衣→脱下衣→穿上衣→脱鞋→尾cut作者写穿下衣 ⇒ 尾cut=除鞋全穿。
  从头到尾都是维持的项保持维持；尾 cut 已显式的项是最晚改动，一律不动。
- **尾 cut 流型项并入维持化**：BGM/音声与生效状态相同的显式值转 引き継ぐ/type 0（显式同值会重播），真实切换保留。
- **状态变化点跳转**：面板按角色分行列出中间 cut 的变化点（首次显示、各项目状态变化、BGM 变化），
  "详情"展开旧值→新值；主行点击跳到对应 cut，**明细行点击跳转并把原生面板定位到对应栏目**
  （选中角色并滚动到 显示/服装/穿脱/饰品/汁液/音声 栏，BGM 打开 BGM 面板）。
- **还原**：一次执行/还原为整体操作，只快照被改写的字段（不含 pose）。
- **入口**：ADV Part 编辑器 `Canvas ADVPart/Manipulate/Button Root` 下注入 `CutSync` 按钮，点击开关 ImGui 面板。

## 使用

1. HEdit 里打开某个 ADV Part，点 Manipulate 工具行新出现的 `CutSync` 按钮打开面板。
2. 面板显示当前 Part 概要（各项目显式值数量）与状态变化点列表。
3. 点"同步尾cut + 维持化"并再次确认执行；结果汇总显示在面板底部（无需优化时按钮禁用）。
4. 不满意时点"还原上次操作"整体还原。
5. 需要改状态时从变化点列表跳到对应 cut，在原生面板里改完面板会自动刷新，可再执行一次。

## 边界

- 仅 HEdit（ADV Part），不处理 HPart；不 patch HPlay/BGM 播放逻辑——BGM 维持用的是游戏数据层自带的
  `引き継ぐ` 条目（空 asset 且非停止，标准数据 id 0）。
- 首 cut 永远不动（它是维持链的锚点）；单 cut part 无可执行。
- 只写原生数据字段，不新增序列化格式；旧场景文件照常保存读取。
