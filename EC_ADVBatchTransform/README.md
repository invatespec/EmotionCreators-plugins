# EC_ADVBatchTransform

在 HEdit 的 ADV Part 编辑器里同时选中多个文本气泡和屏幕特效，一起移动、旋转、改尺寸、改属性、复制、删除，并能撤销包括原生操作在内的改动。

## 操作

| 功能 | 操作 |
|---|---|
| 选中一段 | Shift+点击列表行：以第一次点击的行为起点，到当前行整段选中；起点不随 Shift 移动 |
| 加入/移出单个 | Ctrl+点击列表行 |
| 切换对象 | Tab 下一个 / Shift+Tab 上一个；未选中时 Tab 选第一行、Shift+Tab 选最后一行，到两端循环；多选时停用 |
| 回到单选 | 普通点击某一行 |
| 移动 | 方向键；按住 Shift 步长更大；按住连续移动 |
| 旋转 | Alt+← / Alt+→（Alt+→ 顺时针）；按住 Shift 步长更大 |
| 鼠标旋转 | 按住 D 拖动任一选中对象 |
| 改尺寸 | 拖任一选中对象的角柄，其他对象按相同比例变化 |
| 切换中心 | G：各自中心 / 整组中心 |
| 图层顺序 | 多选时点任一选中行的上下箭头，整组移动一位 |
| 批量复制 | 多选时点列表上方的原生复制按钮，整组各复制一份，选中切到副本 |
| 批量删除 | 多选时点列表上方的原生删除按钮，整组一起删除 |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y（焦点在文本框内时重做文字，框外重做对象操作） |
| 文本撤销/恢复 | 光标在槽位文本框内时 Ctrl+Z 撤销文本、Ctrl+Y 恢复；焦点在框外时这两个键只作用于对象 |
| 拖动输入框改值 | 在位置、角度、尺寸、字号、行距、描边宽度、文字范围四边的输入框上按住左右拖动，松手即生效；单击仍进文字编辑 |

## 行为说明

- 属性面板显示主对象，也就是最后点击或最后 Shift/Ctrl 加入的那一行。取消主对象时，剩下成员里最后加入的那个接任主对象。
- 区间起点只在普通点击、Tab 切换时重设；Ctrl 增减成员不改变起点，连续 Shift 都以同一起点重新划区间。
- Tab 切换始终是单选：多选时按 Tab 不生效，避免打散整组选中。
- 多选时面板上的位置、角度、尺寸、描边宽度、文字颜色、描边颜色都按“设为同一值”处理：改主对象的数值，其他成员跟随；撤销一次整体还原。
- 点开气泡的 Text1/Text2 后，面板和快捷键只作用于这个槽位；槽位打开期间暂停批量操作，普通方向键交还给相机。
- 拖动途中按 G，从下一次拖动开始生效。
- 整组中心模式：旋转时各对象位置绕整组中心转；改尺寸时各对象到中心的距离按同一比例缩放。
- 改尺寸只改框的大小，字号不变。
- 批量复制出的副本叠在原对象原位，选中切到副本组，可直接拖开。原生复制/删除按钮在单选时行为不变。
- 批量删除后主对象为空，撤销一次整组按原图层顺序放回；批量复制的撤销一次删掉整组副本并恢复复制前的选中。

## 撤销范围

- 插件操作：批量拖动、方向键、Alt 旋转、整组图层移动、槽位旋转、面板批量修改、批量复制、批量删除。
- 原生操作：单个对象的拖动（移动/旋转/拉角柄）、面板数值与滑块、颜色面板选色、复位按钮、列表单行上下箭头、复制、新增、删除。
- 文字槽位（Text1/Text2）面板的全部字段：文本内容、字体、字号、行距、动画、方向、自动换行、效果、颜色、描边色与宽度、范围四边、旋转。
- 文本内容有独立的历史：在文本框内 Ctrl+Z/Ctrl+Y 撤销恢复文本，按输入停顿分段（连续打字合并为一步），Text1/Text2 共用一条，与对象变换撤销互不影响。切 cut、离开 Part 时清空。
- 撤销按编辑顺序回放：先改槽位字段再改气泡字段时，Ctrl+Z 先还原后改的那一项。
- 对象撤销与重做成对：误按 Ctrl+Z 把新建对象撤掉后，Ctrl+Y 用同一实例把它放回并重新选中。新的编辑会清空重做栈。
- 一次拖动或一次输入算一步；按住拖动颜色拾取只记一步。
- 切换 cut、离开 Part 后清空；不支持重做。
- 删除的撤销会按保留的数据重建原对象，实例与图层位置都还原。

## 安装

把 `EC_ADVBatchTransform.dll` 放进 `BepInEx/plugins/`。

## 配置

按键、步长、撤销上限、默认中心模式可在 `BepInEx/config/com.rainbowing.ec.advbatchtransform.cfg` 或 F1 插件设置里修改。切换对象的两个按键分别是 `Keys/CycleNext`（默认 Tab）和 `Keys/CyclePrev`（默认 Shift+Tab）。

## 说明

- 只写原生数据字段（位置、角度、尺寸、颜色、描边、图层顺序），不装插件也能正常打开保存的场景。
- 拖动改尺寸的对象本身有旋转时，比例按它自身的轴计算，其他对象得到的是近似结果。
