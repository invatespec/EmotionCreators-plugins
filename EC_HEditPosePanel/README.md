# 姿势面板使用说明

在 姿势调整 里保存、复用**手势**和**裙子**姿势，并微调手指/裙子骨骼。

## 怎么打开

1. 进入 **姿势调整**
2. 点主面板右上角的 **▶** 展开姿势面板；再点 **◀** 收起

主面板可拖动；姿势面板会跟着主面板贴在一侧。

## 面板布局

从上到下：

| 区域 | 做什么 |
|---|---|
| 标题栏 | 姿势库开关缩略图（◉ / ○） |
| 手势 / 裙子 | 两个页签，库互相独立 |
| 文件夹 | 分类管理 |
| 姿势列表 | 点选已保存姿势 |
| 命令 | 保存 / 应用 |
| Guide 调整 | 滑条预览展开/收拢 |

## 手势

### 保存

1. 角色切到对应手的 **手 FK**
2. 摆好姿势
3. 选好文件夹，点 **保存左手** 或 **保存右手**
4. 输入名字 → 确定

手势数据是左右通用的：左手存的可以应用到右手，反过来也行。

### 应用

1. 在列表里点选一个姿势（不会立刻改角色）
2. 点 **应用左手** 或 **应用右手**
3. 若当前不是手 FK，会自动切过去再写入

### 同名覆盖

名字已存在时：

1. 会询问问是否 **覆盖姿势数据**
2. 接着再问是否 **替换缩略图**
   - **替换**：数据 + 新截图
   - **保留**：只改姿势，缩略图不动
   - **取消**：什么都不改

## 裙子

### 保存

1. 启用 **裙子 FK**
2. 摆好姿势
3. 切到 **裙子** 页签 → **保存** → 起名

### 应用

1. 点选姿势
2. 点 **应用**
3. 未开裙子 FK 时会自动开启再写入

## 复制 / 反向粘贴

手势、裙子两页都可用，用来快速把一侧姿势左右镜像到对称侧：

1. Guide 调整 区用切换键选 **单个** 或 **整串**（控制复制粒度）
2. 场景里选中源 guide（单个）或源串根（整串）
3. 点 **复制**
4. 场景里再选中目标 guide / 目标串根
5. 点 **反向粘贴** —— 剪贴板里的局部旋转按左右镜像后写入目标

- **整串** = 当前选中节 + 其后（末端方向）的节，不含前面的节
- 剪贴板只存旋转，切场景后仍可粘贴；链对链按下标对齐，贴到更深串时只贴前几根，尾部不动
- 手部镜像只作用于手指根节；裙子镜像 `x` 不变、`y/z` 取负

## 文件夹与姿势管理

- **+** 新建文件夹
- **✎** 重命名
- **−** 删除（有内容会二次确认）

规则：

- 手势库 / 裙子库分开
- 只支持一层文件夹，不能嵌套
- 默认文件夹不能删，可以改名
- 每个文件夹最多 **50** 个姿势
- 按名字自然排序

## 缩略图

- 新建姿势保存成功后，会自动截一张当前画面作预览
- 点姿势名：打开独立缩略图窗；再点同一条：关闭
- 标题栏 **◉ / ○**：全局开/关缩略图显示
- 缩略图窗可拖；大小在 BepInEx 配置里选 小 / 中 / 大（默认小）

## Guide 调整

用来快速调节手指或裙子单串骨骼的展开/收拢状态。

1. 手势页：点 **左手 / 右手** 切换目标手，再点 **单个 / 整串** 切复制粒度  
   裙子页：点 **单个 / 整串** 切复制粒度；先在场景里选中要调的裙子 Guide
2. 选模式：**展开** 或 **收拢**
3. 拖滑条 **-100 ~ +100** 预览  
   - 中点 **0** = 当前基线  
4. **确认** 提交；**取消** 还原到基线

注意：

- 未确认时切换手、页签、模式，或开始别的操作，会先还原预览
- 应用已存姿势前，也会先清掉未确认的预览
- 手部：动整只手的手指链，不动手腕/掌根朝向
- 裙子：只动当前选中 Guide 及其末端方向的后代

## 常见问题

**保存按钮没反应 / 提示进 FK**  
对应手或裙子还没开 FK。

**应用后姿势不对边**  
手势是通用的，但应用时要选对「应用左手 / 应用右手」。

**缩略图不显示**  
看标题栏眼睛是否关掉；或该姿势保存时选了「保留」且本来就没有图。

## 文件放哪

姿势存在游戏目录：

```text
UserData/PluginData/EC_HEditPosePanel/
  Hand/<文件夹>/<名字>.echpose + .png
  Skirt/<文件夹>/<名字>.ecspose + .png
```

可直接备份或复制这个文件夹到别的机器。
