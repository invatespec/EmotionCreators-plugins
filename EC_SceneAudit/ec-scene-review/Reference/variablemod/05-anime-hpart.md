## 动画化剪辑 `<anime-cut>`（Ver.0.2 追加）

`<anime-cut>` 命令：可以让片段内的剪辑自动连续播放，实现动画效果。

下面的例子为，让「剪辑 2」到「剪辑 6」以 0.2 秒的间隔连续播放 3 回。

```
<script>
<anime-cut start="1" end="5" count="3" wait="200" mode="seq"/>
</script>
```

- `start` 指定起始剪辑。可以是变量也可以是定值。指定方法和 `<goto-cut>` 的 index 相同。
- `end` 指定结束剪辑。可以是变量也可以是定值。
- `count` 循环次数。可以是变量也可以是定值。（可省略，默认 1）指定为 0 则无限循环，单击即可跳转至 end 的下一剪辑。
- `wait` 播放间隔（毫秒）。可以是变量也可以是定值。（可省略，默认 100 毫秒）
- `mode` 循环模式。（可省略）`seq` = start→end（默认），`rev` = start→end→start。
- `smooth` **（Ver.0.6 新增）** 平滑过渡帧数。可以是变量也可以是定值。（可省略，默认 0 即不平滑）大于 0 时会在剪辑间进行平滑插值过渡。

※start 和 end 无法指定剪辑 1 和结尾剪辑。能指定的只有剪辑 2 到剪辑 49。

※如果间隔设定过短，受电脑配置影响，可能无法达到预期的间隔。

※使用动画化剪辑时，如果同时使用了文本框，建议关闭文本框的动画效果。

※如果在动画化剪辑中使用了脚本，脚本的处理速度会变慢。建议不要这样做。

※镜头移动、剧烈的颜色更换、人物移动之类的行为可能会对用户的身体健康产生影响，请制作者们多为读者着想。

## H 片段设定 `<h-part-set>`（Ver.0.2 追加）

`<h-part-set>` 命令：可以变更 H 片段的动作设定。

```
<script>
<h-part-set automove="1"/>
</script>
```

- `automove` 范围 0 或 1。可以是变量也可以是定值。
  - `0`：默认值。
  - `1`：在 H 片段中达成条件时自动向分支移动。

※如果分支包含最后一项「选择全部可用的绝顶项」，就不会自动移动。
