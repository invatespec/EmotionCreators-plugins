# ■■ `<script>` 脚本的编写 ■■

本 Mod 是通过在对白文本框中以 XML 形式记录脚本，从而实现变量处理、片段与剪辑间跳转等功能。

脚本记录在 `<script>～</script>` 的范围中。记录在一帧剪辑上的脚本，会在这帧剪辑显示出来的时候开始处理。

※因此能够编写脚本的只有 ADV 片段。H 片段中是无法编写脚本的。（但可以通过 `<event-part>` 命令为 H 片段预设脚本。）

首先，制作一个新的对白文本框。选择一个喜欢的文本框即可。

一个范例：

```
<script>
<!--此剧本需要 EC_VariableMod Ver.0.3 以上版本-->
<invisible/>
<initialize/>
</script>
```

然后进行「测试 PLAY」，如果记述脚本的文本框没有显示的话，就表明已成功执行。

脚本内可以自行编写注释。格式为 `<!-- 注释内容 -->`。（Ver.0.2 追加）

一个 CUT 中存在多个记述脚本的文本框时，会按从上到下的顺序执行。此外，**不要在一个文本框里记述多个 `<script>` 块**。只有第一个脚本会被执行，之后的内容全部都会被视作文本。

```
<script>
<!--这里会执行-->
<initialize/>
</script>
<script>
不执行，连同在该 script 内的所有文本视为普通文本。
<invisible/>
</script>
```

## 初始化 `<initialize/>`

`<initialize/>` 命令：将所有变量定义初始化。

此外，一个剧本（一张 png）开始时会自动执行 `<initialize/>`。

```
<script>
<initialize/>
</script>
```

※场景结束之际，如果通过选项「返回」等方式跳回到先前片段，建议在那一片段的「剪辑 1」中使用一次此命令。

## 隐藏文本框 `<invisible/>`

`<invisible/>` 命令：隐藏文本框。

如果不使用该命令，脚本文本框会保持显示，但可被执行的脚本部分 `<script>～</script>` 会隐藏。（总而言之，看不到乱七八糟的代码，但是会看到承载代码的文本框。）

```
<script>
<invisible/>
</script>
```
