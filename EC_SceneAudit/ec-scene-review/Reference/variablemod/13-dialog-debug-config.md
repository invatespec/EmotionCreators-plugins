# ■■ 对话框内的变量参照 ■■

对话框内记述着变量名（如 `#hensu1#`）的话，在游戏中会自动被变量的值替换。已定义的变量及系统变量都可以被自动替换。但是，未定义的变量以及已被删除的变量，即使被围在两个 `#` 中间，也会原样显示出来。

# ■■ 关于 Debug ■■

由于变量的状态无法在游戏画面中显示出来，通过更改下述设定，可以生成用于调试的 HTML 文件。

1. 用记事本打开 `BepInEx\config\EC_VariableMod.cfg`
2. 将 `WatchMode` 改为 `true`（默认为 `false`），保存
3. 重启 EC，游玩或者测试 PLAY 带有脚本的剧本
4. 在 `BepInEx` 文件夹内会生成名为 `EC_VariableMod_Debug.html` 的文件
5. 用浏览器打开，即可查看当前变量的状态

变量状态会随脚本执行更新，刷新浏览器即可确认最新状态。系统变量也可输出。动画化剪辑中由于负荷较大，不会输出变量状态。局部变量和区块变量现在也可以输出了。

# ■■ 配置文件 ■■

`BepInEx\config\EC_VariableMod.cfg` 中的可配置项：

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| `WatchMode` | `false` | 设为 `true` 时生成调试 HTML |
| `LimitTime` | `5` | 脚本最大执行时间（秒），超过后强制中断以防止死循环 |
