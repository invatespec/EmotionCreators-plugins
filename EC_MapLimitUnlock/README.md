# EC_MapLimitUnlock

把 HEdit 场景的地图数量上限从 21 提高到 99。

## 行为

- 只放开添加地图按钮的可用判断，地图列表、下拉框、保存与读取都不改。
- 不改场景文件格式与版本号，未装插件的人仍可打开地图数不超过原版上限的场景。
- 加载超过原版上限的场景时，日志会提示一次。

## 安装

把 `EC_MapLimitUnlock.dll` 放进 `BepInEx/plugins/`。

## 说明

- 原版上限按地图条目计（含"なし"），因此原版最多 20 张实际地图，本插件最多 98 张。
- 超过原版上限的场景，对方没装同类插件时无法继续添加地图，但场景本身能打开。
