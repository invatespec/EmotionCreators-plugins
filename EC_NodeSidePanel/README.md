# EC 节点侧边面板

左下角的 **▣**。点一下展开，再点收起。


## 功能

### 找节点
- 上面搜索框，输名字一部分就行
- **▲ / ▼** 在匹配结果里跳转，列表会跟着滚到那一行
- 点列表某一行 = 选中；再点 **「定位」** 画布会挪过去（尽量居中），并用慢闪十字提示节点位置
- **「清除选中」** 清空勾选和高亮

### 连线高亮

定位后面的 **「入线」/「出线」**：按一次亮，再按一次灭，两个方向各管各的。

| 按钮 | 亮哪些线 | 颜色 |
|------|----------|------|
| 入线 | 别的节点**连进来**的线 | 青 |
| 出线 | 选中节点**发出去**的线 | 橙 |

- 选谁：跟位移一样，**勾选优先 → 否则当前夹（含子夹）→ 否则高亮那一个**，所以能多选、能选文件夹
- 亮着的时候换选中，高亮会自己跟过去
- 清除选中 / 收起面板 / 离开节点页，都会自动灭掉
- 一条线既是入又是出，显示橙色

### 排序
- **时间** / **名称** 切换
- **升↑ / 降↓** 翻转顺序

### 文件夹
用来自己分组，**只存在插件配置的config.xml里**，不会写进场景 `.png`。

| 按钮 | 作用 |
|------|------|
| +文件夹 | 新建文件夹；当前有选中夹就建子夹 |
| 重命名 | 改当前选中文件夹名字 |
| 删文件夹 | 删除文件夹；里面的节点回到未分组 |
| 移入 | 把**勾选**的节点移入**当前选中的文件夹** |
| 移出 | 勾选节点移出文件夹 |

- 文件夹行点一下 = 选中夹（移入目标）
- 节点行左边勾选 = 多选
- Start / End 在「系统」区，不能进夹

### 画布滑条
- 列表**左边**竖滑条、**下面**横滑条，拖着平移大画布
- 鼠标停在对应滑条上时，**滚轮**也可调该方向
- 中键拖画布时滑条会跟着动

### 节点位移
底栏右边 **「节点操作」+ ▶**：打开侧边小窗，下半部是位移十字。  
点 ↑↓←→ 挪节点。

**挪谁：** 勾选优先 → 否则当前夹（含子夹）→ 否则高亮那一个。  
**步进：** 默认 20；**Ctrl** 细调 2；**Shift** 大步 100。

### 面板内连线

同一个小窗的上半部。**只在选中恰好一个节点时能用**，否则整块变灰。

目标节点一律**填名字**（不区分大小写）。重名会报错，先去改名。

#### 出方向：选中节点 → 别人

1. `◀ 输出 N ▶` 挑一个输出槽，右边会显示这个槽现在连着谁（或「空」/「未启用」）
2. **目标**框填一个节点名 → 点「连接」→ 下面出来「确认 / 取消」，点「确认」才真的写

#### 入方向：别人 → 选中节点

**来源**框填节点名，多个用 `,` 分隔（全角 `，` 也认），比如 `A,B,C` → 点「连接」→ 再点「确认」。

- 每个来源默认用它自己**第一个「已启用」**的输出槽
- 想指定用哪个槽，写 `名字:槽号`，比如 `A,B:2,C`
- 某个来源连不上只有它报错，其余照常连上

#### 会覆盖，注意

**两个方向都是直接覆盖**：槽上原来连着谁就被顶掉谁。所以点「连接」不会立刻生效，一定要再点一次「确认」——这一步就是防手滑的。点错了点「取消」，或者切走选中也会自动撤掉待确认状态。

#### 结果看哪里

面板里只有一个短状态，够你扫一眼知道成没成：

| 面板显示 | 意思 |
|---|---|
| 已连接 | 全部成功 |
| 未完全连接 | 一部分成功（批量来源才会出现） |
| 未连接 | 全部失败 |

**具体哪条为什么失败，去看控制台**（BepInEx 日志窗口，或 `BepInEx/LogOutput.log`），搜 `connect:`。批量来源会逐条列出 `✔` / `✘` 和原因，比如：

```
[Warning:EC Node Side Panel] connect: ✔ A.输出0 → 本节点  ✘ 找不到节点「Bb」
```

常见失败原因：名字打错、有重名节点（`节点名「X」不唯一`，先去改名）、连自己、槽没开（H 节点结束条件是「未使用」，或 ADV 选项不够）、目标是开始节点（没有输入口）。

面板上的短状态 8 秒后自动消失，日志会一直留着。

> 连接结果写进游戏原本的节点数据，**跟着场景一起存**，不进插件的 config.xml。

### 画布扩展
扩展画布大小，默认5x；可在配置项里修改， 回到标题/重启游戏，重新加载场景后生效。

## 配置路径

每个场景一份：

`UserData/edit/Otherscene/nodepanel/<场景标题>/config.xml`


改文件夹、排序之类会防抖自动存；保存场景时也会立刻写一次。场景没标题时只记在内存，关游戏就没了。

### 改场景标题

- **不自动迁移**旧目录。保存场景后，后续写入跟到**新场景标题**目录。
- 若要沿用旧配置：先**收起面板**（会落盘）→ 资源管理器把旧文件夹内容迁到新场景标题目录 → **展开面板**（热重载读盘）。
- 改名并保存后若内存里已是最新分组，新目录会直接有一份正确配置；旧目录可手动删。
