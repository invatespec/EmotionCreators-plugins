# EC 节点侧边面板

左下角的 **▣**。点一下展开，再点收起。


## 功能

### 找节点
- 上面搜索框，输名字一部分就行
- **▲ / ▼** 在匹配结果里跳转，列表会跟着滚到那一行
- 点列表某一行 = 选中；再点 **「定位」** 画布会挪过去（尽量居中），并用慢闪十字提示节点位置
- **「清除选中」** 清空勾选和高亮

### 排序
- **时间** / **名称** 切换
- **升↑ / 降↓** 翻转顺序

### 文件夹
用来自己分组，**只存在插件配置的config.xml里**，不会写进场景 `.png`。

| 按钮 | 作用 |
|------|------|
| +文件夹 | 新建文件夹；当前有选中夹就建子夹 |
| 重命名 | 改当前选中文件夹名字 |
| 删文件夹 | 删除文件夹；里面的节点回到未分组 |
| 移入 | 把**勾选**的节点移入**当前选中的文件夹** |
| 移出 | 勾选节点移出文件夹 |

- 文件夹行点一下 = 选中夹（移入目标）
- 节点行左边勾选 = 多选
- Start / End 在「系统」区，不能进夹

### 画布滑条
- 列表**左边**竖滑条、**下面**横滑条，拖着平移大画布
- 鼠标停在对应滑条上时，**滚轮**也可调该方向
- 中键拖画布时滑条会跟着动

### 节点位移
底栏右边 **「节点位移」+ ▶**：打开小十字。  
点 ↑↓←→ 挪节点。

**挪谁：** 勾选优先 → 否则当前夹（含子夹）→ 否则高亮那一个。  
**步进：** 默认 20；**Ctrl** 细调 2；**Shift** 大步 100。

### 画布扩展
扩展画布大小，默认5x；可在配置项里修改， 回到标题/重启游戏，重新加载场景后生效。


---

## 配置路径

每个场景一份：

`UserData/edit/Otherscene/nodepanel/<场景标题>/config.xml`


改文件夹、排序之类会防抖自动存；保存场景时也会立刻写一次。场景没标题时只记在内存，关游戏就没了。

### 改场景标题

- **不自动迁移**旧目录。保存场景后，后续写入跟到**新场景标题**目录。
- 若要沿用旧配置：先**收起面板**（会落盘）→ 资源管理器把旧文件夹内容迁到新场景标题目录 → **展开面板**（热重载读盘）。
- 改名并保存后若内存里已是最新分组，新目录会直接有一份正确配置；旧目录可手动删。
